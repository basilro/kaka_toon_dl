# kaka_toon_dl

카카오웹툰(webtoon.kakao.com) 무료/기다무 회차를 자동으로 내려받는 FlaskFarm 플러그인.

## 주요 기능

- **설정** — 쿠키(로그인) 주입, 다운로드 경로, 폴더명 형식, 회차당 처리량, 기다무/소장권 사용 여부,
  출력 포맷(webp 등), 프록시, 압축, 알림 웹훅 등을 설정한다.
- **연재 목록** — 카카오웹툰 요일별 연재작 전체를 한 화면에서 불러와, 요일 필터·검색으로
  원하는 작품을 골라 **체크 한 번으로 다운로드 스케줄에 등록**한다. 작품 코드를 일일이
  찾아 입력할 필요가 없다. 이미 등록된 작품은 표시되며 중복 등록되지 않는다.
- **수동 다운로드** — URL 또는 작품 코드로 특정 작품을 즉시 내려받는다.
- **진행 상황** — 현재 다운로드 진행 상태를 실시간으로 확인한다.
- **다운로드 이력** — 처리된 작품/회차 기록을 조회한다.

## 폴더명 형식

작품 폴더와 회차 폴더의 이름을 설정 화면에서 정할 수 있다.
규칙은 하나다. 중괄호로 감싼 말만 값으로 바뀌고, 나머지 글자는 적은 그대로 쓰인다.
자동 다운로드와 수동 다운로드가 같은 설정을 쓴다.

| 쓸 수 있는 말 | 바뀌는 값 |
| --- | --- |
| `{title}` | 작품명 |
| `{author}` | 작가명 (글 작가 먼저, 그림 작가가 다르면 뒤에) |
| `{subtitle}` | 회차명 |
| `{no}` | 회차 번호 (자릿수는 별도 설정) |
| `{title_id}` | 카카오웹툰 작품 번호 |

기본값은 작품 `{title}`, 회차 `{no}_{subtitle}`, 회차 번호 자릿수 `4` 이고, 결과는
`나 혼자만 레벨업/0003_3화/` 이다. 회차 형식을 `[{no}] {subtitle}` 로 두면
`[0003] 3화` 가 된다. 설정 화면의 예시 버튼을 누르면 입력란이 채워지고,
미리보기 버튼으로 실제 저장 경로를 확인할 수 있다.

- `{no:04d}` 같은 파이썬 서식은 적을 필요가 없다. 자릿수는 별도 설정으로 정하고,
  예전에 적어 둔 서식도 그대로 동작한다.
- 회차 번호 자릿수를 `0` 으로 두면 채우지 않는다(`0003` 대신 `3`).
- 작가 이름은 작품 정보를 읽을 때 함께 기억해 둔다. 아직 한 번도 다루지 않은 작품이라
  이름을 모르면 그 자리를 비워 두고 로그에 경고를 남긴다.
- 파일명에 쓸 수 없는 문자(`\ / * ? : " < > |`)는 자동으로 `_` 로 바뀐다.
- 모르는 말을 적으면 저장은 되지만 실제 다운로드는 기본값으로 처리하고 로그에 경고를 남긴다.
- 형식을 바꿔도 이미 받아 둔 폴더의 이름은 바뀌지 않는다. 새로 받는 회차부터 적용된다.
- ZIP 압축을 켜면 아카이브 이름도 회차 폴더명을 따른다. 이미 받은 회차는 다운로드
  이력으로 판정하므로, 형식을 바꿨다고 다시 받지는 않는다.

## 동작 방식

- 등록된 작품의 무료·기다무·소장 회차를 스케줄에 따라 자동 수집한다.
- 카카오웹툰 BFF API를 사용하며, 로그인 쿠키로 사용자별 보유 티켓/대기무료 상태를 반영한다.
- 연재 목록은 공개 timetable API(`section/v2/timetables/days`)에서 가져오므로 로그인이 필요 없다.
